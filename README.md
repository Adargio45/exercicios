# Exercícios em Java ☕

Repositório criado para registrar minha evolução nos estudos de **Java**, reunindo exercícios de lógica de programação, algoritmos e resolução de problemas.

## 🎯 Objetivo

Praticar fundamentos da programação e desenvolver, de forma progressiva, raciocínio lógico, capacidade de resolução de problemas e domínio da linguagem Java.

## 📚 Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados com `Scanner`
- Operadores e expressões matemáticas
- Estruturas condicionais
- Estrutura `switch`
- Estruturas de repetição
- `for` e incremento
- Arrays
- Resolução de problemas de programação
- Exercícios da plataforma **beecrowd (BEE)**

## 📂 Organização

Os exercícios estão concentrados no diretório `src/`.

Alguns exemplos presentes no repositório:

- `Array.java` — prática com arrays e entrada de dados.
- `CalculadoraSwitch.java` — prática com `switch` para operações da calculadora.
- `EntradaDeDados.java` — exercícios relacionados à entrada de dados.
- `IncrementoComFor.java` — prática com laços `for` e incremento.
